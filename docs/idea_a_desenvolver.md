## OpenCity — Report and solve urban problems
Users report problems in their city:
 - potholes
 - broken streetlights
 - broken lamps
 - etc...

The app displays all reports on a map and lets users follow their progress.

### Main features
- Create an account
- Upload a photo, description and location of a problem (within some categories)
- View reports near the user (topdown map with markers)
- Comment on reports
- Change status by admins: “reported,” “under review,” “being repaired,” “resolved”, etc...
- Earn points for useful reports and confirmations
- Receive notifications when a report changes status, on comments on a report a user made, etc...
- Filter the map by category or urgency
- Admin dashboard for managing reports
- (Optional) Statistics showing which areas have the most problems
